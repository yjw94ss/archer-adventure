# 弓箭手冒险 · Archer Adventure

一个致敬《冒险岛》的 2D 横版卷轴动作 RPG 网页游戏，主角职业为**弓箭手**。纯原生 HTML + CSS + Canvas 实现，无任何构建步骤、无第三方依赖，双击 `index.html` 即可开玩。

## 玩法特色

**弓箭手核心战斗**
- 远程射击、自由瞄准：鼠标指向即射角方向，或用 `↑/↓` 切换上/下/斜上/斜下八向射击
- 四大技能：三连箭、贯穿箭、箭雨、鹰眼（暴击增益），均有独立冷却与 MP 消耗
- 蓄力手感、命中飘字、暴击与击退反馈

**地图与移动**
- 多层平台地形，含森林、斜坡、魔族领地三个区域
- 绳索 / 梯子攀爬，可跳跃、二段下坠、跳下平台
- 平滑跟随相机与视差背景（远山、云、森林三层）

**成长系统**
- 击杀怪物获得经验、金币，升级后获得能力点，可自由加点力量/敏捷/体质
- 战利品掉落：武器、防具、饰品、药水，装备后实时改变攻击、防御、暴击
- 任务系统：接取 → 击杀计数 → 完成领奖，含三阶段主线与蘑菇王 BOSS

**UI 界面（重点打磨）**
- 左上角角色面板：圆形头像、等级徽章、HP/MP 条、EXP 进度条、战斗属性速览
- 右上角小地图：实时绘制地形、怪物红点、玩家箭头、BOSS 骷髅标记
- 底部技能栏：图标手绘 Canvas、冷却扇形遮罩、剩余秒数、MP 不足预警、按键提示
- 背包面板：装备栏 + 4×5 道具格、数量角标、悬停详情、点击使用/装备、右键卸下
- 属性面板：头像、等级、属性加点、装备加成汇总
- 任务面板：任务卡片、状态徽章、进度条、奖励预览、一键领奖
- 战斗日志、BOSS 血条、受伤红屏、升级横幅、飘字与特效层

## 操作

| 按键 | 功能 |
| --- | --- |
| `A` `D` / `←` `→` | 左右移动 |
| `空格` | 跳跃（`↓` + `空格` 跳下平台） |
| `↑` `↓` | 攀爬绳索 / 梯子，同时调整射角 |
| `Z` / 鼠标左键 | 普通射击（鼠标可自由瞄准） |
| `1` `2` `3` `4` | 三连箭 / 贯穿箭 / 箭雨 / 鹰眼 |
| `5` `6` | 红药 / 蓝药 |
| `I` `C` `T` `H` | 背包 / 属性 / 任务 / 帮助 |
| `ESC` | 关闭面板 |

## 项目结构

```
archer-adventure/
├── index.html          # 页面骨架与全部 UI 节点
├── css/
│   └── ui.css          # 冒险岛风格 UI 主题、布局、动画
└── js/
    ├── config.js       # 数值配置：技能、怪物、道具、任务、成长公式
    ├── world.js        # 地图平台、绳索、视差背景绘制
    ├── entities.js     # 弓箭手、怪物、箭矢、掉落物、粒子
    ├── ui.js           # HUD、小地图、背包、属性、任务面板渲染
    └── main.js         # 主循环、输入、战斗调度、相机、场景管理
```

## 技术要点

- **固定步长物理**：60Hz 累加器驱动，跳跃高度与手感不受帧率影响
- **AABB + 单向平台**：自下而上穿越、站立检测、`↓+空格` 主动下坠
- **Canvas 手绘美术**：角色、怪物、图标、地形全部代码绘制，零图片资源
- **等比缩放舞台**：`#stage` 固定 1280×720，按窗口尺寸整体 `scale`，任意分辨率不变形
- **无构建运行**：ES5 兼容写法与普通 `<script>` 顺序加载，可直接托管在任意静态服务器

## 本地运行

```bash
# 方式一：直接打开
open index.html

# 方式二：本地静态服务器（推荐，避免个别浏览器的 file:// 限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 调试参数（可选）

仅供开发排查使用，不影响正常游玩：

| 参数 | 作用 |
| --- | --- |
| `?play=1` | 跳过开始界面直接进入游戏 |
| `?test=1` ~ `?test=9` | 演示各场景与面板（战斗、背包、属性、任务、帮助、BOSS 等） |
| `?test=sim&sec=45` | 固定步长无头模拟，输出击杀/经验/掉落等状态，用于回归测试 |
