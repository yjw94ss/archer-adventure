# 弓箭手冒险 · Archer Adventure

一个致敬《冒险岛》的 2D 横版卷轴动作 RPG 网页游戏，主角职业为**弓箭手**。纯原生 HTML + CSS + Canvas 实现，无任何构建步骤、无第三方依赖，双击 `index.html` 即可开玩。

![Gameplay](https://img.shields.io/badge/platform-Web-orange) ![No Build](https://img.shields.io/badge/build-none-brightgreen) ![Vanilla JS](https://img.shields.io/badge/JS-vanilla-yellow)

## 玩法特色

**弓箭手核心战斗**
- 远程射击、自由瞄准：鼠标指向即射角方向，或用 `↑/↓` 切换上/下/斜上/斜下八向射击
- 四大技能：三连箭、贯穿箭、箭雨、鹰眼（暴击增益），均有独立冷却与 MP 消耗
- 蓄力手感、命中飘字、暴击与击退反馈

**地图与移动**
- 四章主线地图，每章一张独立主题场景，走到地图尽头按 `↑` 进入下一章
- 多层平台地形、绳索 / 梯子攀爬，可跳跃、二段下坠、跳下平台
- 平滑跟随相机与视差背景（每张地图独立配色、云海、钟乳石、毒雾、浮空浮岛）
- 小地图按主题换肤，实时显示地形、怪物红点、玩家箭头、BOSS 骷髅标记

## 关卡流程

| 章节 | 地图 | 推荐等级 | 入口等级 | 章节 BOSS |
| --- | --- | --- | --- | --- |
| 第一章 | 蘑菇森林 | Lv.1 - 10 | — | 蘑菇王 Lv.12 |
| 第二章 | 幽暗洞穴 | Lv.8 - 17 | Lv.8 | 石魔领主 Lv.17 |
| 第三章 | 毒雾沼泽 | Lv.14 - 21 | Lv.14 | 毒沼蛙王 Lv.20 |
| 第四章 | 天空遗迹 | Lv.20 - 28 | Lv.20 | 天空守望者 Lv.28 |

- 每章 3 张任务：小怪讨伐 ×2 + 守关 BOSS ×1，共 12 条委托，带等级门槛
- 进入新地图会自动提示当前可接的委托；讨伐天空守望者后触发全章通关结算

**成长系统**
- 击杀怪物获得经验、金币，升级后获得能力点，可自由加点力量/敏捷/体质
- 战利品掉落：武器、防具、饰品、药水与各章素材（蜗牛壳、魔法矿石、毒囊、遗迹符文），装备后实时改变攻击、防御、暴击
- 任务系统：接取 → 击杀计数 → 完成领奖，共 12 条跨四章的主线委托，含等级门槛与章节 BOSS

**UI 界面（重点打磨）**
- 左上角角色面板：圆形头像、等级徽章、HP/MP 条、EXP 进度条、战斗属性速览
- 右上角小地图：实时绘制地形、怪物红点、玩家箭头、BOSS 骷髅标记
- 底部技能栏：图标手绘 Canvas、冷却扇形遮罩、剩余秒数、MP 不足预警、按键提示
- 背包面板：装备栏 + 4×5 道具格、数量角标、悬停详情、点击使用/装备、右键卸下
- 属性面板：头像、等级、属性加点、装备加成汇总
- 任务面板：任务卡片、状态徽章、进度条、奖励预览、一键领奖
- 战斗日志、BOSS 血条、受伤红屏、升级横幅、飘字与特效层

## 操作

**键盘 / 鼠标**

| 按键 | 功能 |
| --- | --- |
| `A` `D` / `←` `→` | 左右移动 |
| `空格` | 跳跃（`↓` + `空格` 跳下平台） |
| `↑` `↓` | 攀爬绳索 / 梯子，同时调整射角 |
| `Z` / 鼠标左键 | 普通射击（鼠标可自由瞄准） |
| `1` `2` `3` `4` | 三连箭 / 贯穿箭 / 箭雨 / 鹰眼 |
| `5` `6` | 红药 / 蓝药 |
| `I` `C` `T` `H` | 背包 / 属性 / 任务 / 帮助 |
| `ESC` | 关闭面板 |

**手机 / 平板（触屏）**

| 操作 | 功能 |
| --- | --- |
| 左下摇杆 | 左右移动；向上/向下攀爬绳索梯子；向上推可进传送门 |
| 右下「射」 | 按住连续射击，**自动锁定最近的敌人** |
| 右下「跳」 | 跳跃；摇杆向下 + 跳 可从单向平台跳下 |
| 拖动画面 | 手动精确瞄准，松手约 2 秒后恢复自动瞄准 |
| 技能四键 | 三连箭 / 贯穿箭 / 箭雨 / 鹰眼，按钮上显示冷却秒数 |
| 红 / 蓝药 | 即时回血 / 回蓝，角标显示剩余数量 |
| 右上按钮 | 背包 / 属性 / 任务 / 帮助 / 全屏 |

竖屏打开会提示旋转手机；触屏控件与面板都按真实屏幕像素渲染，不会被舞台缩放压小。

## 项目结构

```
archer-adventure/
├── index.html          # 页面骨架与全部 UI 节点（含触屏控件层）
├── css/
│   ├── ui.css          # 冒险岛风格 UI 主题、布局、动画
│   └── mobile.css      # 触屏控件、紧凑 HUD、面板反向缩放、竖屏提示
└── js/
    ├── config.js       # 数值配置：技能、怪物、道具、任务、成长公式
    ├── world.js        # 四张地图的 MAPS 注册表、平台/绳索/传送门、主题化背景绘制
    ├── entities.js     # 弓箭手、怪物（含四大 BOSS）、箭矢、掉落物、粒子
    ├── ui.js           # HUD、小地图、背包、属性、任务面板、通关结算、手机 HUD
    └── main.js         # 主循环、输入（键鼠 + 触屏）、战斗调度、相机、关卡流程
```

## 技术要点

- **固定步长物理**：60Hz 累加器驱动，跳跃高度与手感不受帧率影响
- **AABB + 单向平台**：自下而上穿越、站立检测、`↓+空格` 主动下坠
- **Canvas 手绘美术**：角色、怪物、图标、地形全部代码绘制，零图片资源
- **等比缩放舞台**：`#stage` 固定 1280×720，按窗口尺寸整体 `scale`，任意分辨率不变形
- **触屏反向缩放**：舞台缩小多少，触屏控件与面板就放大多少（`--inv`），保证按钮与文字始终是真实屏幕像素大小
- **自动瞄准**：触屏射击锁定 700px 内最近的敌人，同时驱动角色朝向与箭矢角度；手动拖动画面可临时接管
- **无构建运行**：ES5 兼容写法与普通 `<script>` 顺序加载，可直接托管在任意静态服务器

## 本地运行

```bash
# 方式一：直接打开
open index.html

# 方式二：本地静态服务器（推荐，避免个别浏览器的 file:// 限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 调试参数（可选）

仅供开发排查使用，不影响正常游玩：

| 参数 | 作用 |
| --- | --- |
| `?play=1` | 跳过开始界面直接进入游戏 |
| `?test=1` ~ `?test=9` | 演示各场景与面板（战斗、背包、属性、任务、帮助、BOSS 等） |
| `?test=map&m=swamp&lv=20&sx=3040&sy=1300` | 指定地图 / 等级 / 坐标直接进入，便于截图检查 |
| `?test=portalsim` | 静态校验所有传送门目标与落点，并跑完整传送链 |
| `?test=bosskill&m=ruins` | 秒杀指定地图的 BOSS，验证血条、掉落与通关结算 |
| `?test=ending` | 直接预览全章通关结算界面 |
| `?test=sim&sec=45&m=cave&lv=12&sx=600&sy=1360` | 固定步长无头模拟，输出击杀/经验/掉落等状态，用于回归测试 |
| `?test=aim` | 触屏回归：摇杆方向映射、按键按住/松开、自动瞄准命中 |
| `?touch=1` / `?touch=0` | 强制开启 / 关闭触屏模式（桌面调试手机 UI 用） |
| `?notrans=1` | 关闭所有过渡动画（无头截图用） |
